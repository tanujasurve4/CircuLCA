🌱 CircuLCA

AI-Driven Life Cycle Assessment Tool for Advancing Circularity and Sustainability in Metallurgy and Mining

CircuLCA is an AI-driven Life Cycle Assessment (LCA) platform designed specifically for the mining and metallurgy sector.

The platform aims to replace time-consuming manual LCA processes with automated environmental impact analysis, predictive analytics, circularity assessment, and interactive dashboards to support better sustainability and decision-making.

📌 Problem Statement

Traditional Life Cycle Assessment in mining and metallurgy can require weeks or months of manual data collection, processing, and reporting.

The lack of digital tracking and automated environmental analysis makes it difficult for industries to obtain timely and actionable sustainability insights.

CircuLCA addresses these challenges by providing an AI-driven digital platform for automated LCA, predictive environmental analysis, and circularity assessment.

▶️ How to Run

1. Clone the Repository

git clone https://github.com/tanujasurve4/CircuLCA.git

2. Open the Project

cd CircuLCA

3. Install Dependencies

pip install -r requirements.txt

4. Run the Streamlit Application

streamlit run LCA7.py

The application will open in your browser.
